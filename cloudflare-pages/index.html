Where do I find my Webull credentials?

On a desktop, open the Webull web client, sign in, then in your browser's developer tools (F12) check the Network tab for any API call to tradeapi.webullbroker.com. The request headers contain:

  • access_token — your session token
  • did — your device ID (optional)
  • The URL path includes your account ID (e.g. /v2/home/123456)

Paste those three values into the Setup screen. That's it.
